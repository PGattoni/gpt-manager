# AI Chat Bulk Manager (AICBM)

Personalização do [AI Chat Bulk Manager original](https://github.com/learnerLj/ai-chat-bulk-manager), de Luo Jiahao (MIT), com alterações para organização de conversas do ChatGPT.

## Instalar

Abra **https://pgattoni.github.io/aicbm/** e clique em **Instalar ou atualizar no Tampermonkey**.

- Script: [aicbm.user.js](https://pgattoni.github.io/aicbm/aicbm.user.js)
- Metadados para atualização: [aicbm.meta.js](https://pgattoni.github.io/aicbm/aicbm.meta.js)
- Código em TXT: [aicbm.txt](https://pgattoni.github.io/aicbm/aicbm.txt)

## Versão publicada

**v0.9.2:** adaptação da versão v0.9.1 aos endereços de instalação e atualização deste repositório, sem mudanças deliberadas nas funções de gerenciamento.

## Atenção

- Mantenha apenas uma versão do script habilitada no Tampermonkey.
- Este código executa ações de arquivar e excluir na conta, inclusive em lote. Revise suas seleções.
- Tags, cores e proteções atuais são locais; ainda não há sincronização com Google Drive.
- Agrupamento por IA e sincronização são funcionalidades planejadas, não publicadas.
- O código do script é público. Não publique dados privados, tokens ou exportações de conversas neste repositório.
